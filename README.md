# Stylish By Design (SBD)

Stylish By Design (SBD) is a modern eCommerce platform focused on delivering carefully curated products with strong aesthetics, usability, and quality. The goal of SBD is to combine design, functionality, and a seamless shopping experience into one elegant digital storefront.

---

## 🛍️ About the Project

Stylish By Design was created to be more than just an online store. It is a brand-driven eCommerce solution designed for users who value:

* Clean and modern design
* High-quality products
* Simple and intuitive navigation
* Secure and reliable purchasing experience

This project is built with scalability and maintainability in mind, allowing future expansion such as new product categories, integrations, and internationalization.

---

## 🚀 Features

* Product catalog with detailed descriptions and images
* Category-based navigation
* Shopping cart management
* Secure checkout process
* User authentication (sign up / login)
* Order tracking
* Responsive design (desktop & mobile)
* Admin panel for product and order management *(planned)*

---

## 🧰 Tech Stack

This project uses a robust and scalable stack, suitable for enterprise-level and modern web applications:

* **Frontend:** Angular
* **Styling:** Angular Material / Tailwind CSS
* **Backend:** Java (Spring Boot)
* **Database:** PostgreSQL
* **Authentication:** JWT (JSON Web Tokens)
* **API:** RESTful APIs
* **Payments:** Stripe / PayPal *(planned)*

---

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/your-username/stylish-by-design.git

# Navigate to the project folder
cd stylish-by-design

# Install dependencies
npm install

# Run the project
npm run dev
```

---

## ⚙️ Environment Variables

Create a `.env` file in the root directory and configure the following variables:

```env
DATABASE_URL=
JWT_SECRET=
PAYMENT_PROVIDER_KEY=
```
